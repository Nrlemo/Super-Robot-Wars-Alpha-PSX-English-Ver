# Fuente inglesa de 1 byte para 8FONT_R.TIM (celdas de 8x16, mitad derecha, filas 0-5 = bytes 0x20-0x7F).
# Cada glifo: línea "== <carácter>" (o "== 0xNN") y 11 filas de ancho fijo por glifo.
#   fila 0 = acentos/extra, fila 1 = tope de mayúsculas/ascendentes, fila 3 = tope de x-height,
#   fila 8 = línea base (última fila de tinta), filas 9-10 = descendentes.  Fila n → fila n+4 de la celda.
# '#' = tinta (color 1). La sombra (color 3, desplazada +1,+1) la agrega font_build.py.
# Avance VWF = ancho del dibujo + 1, salvo que se indique "adv=N" en la línea "==".
# "keep" = conservar el glifo y el avance originales (8 px): 0x20; los dígitos están redibujados con adv=8, porque los menús
#   alinean números rellenando con espacios (ver notes/fuente_en.md). El espacio del texto inglés es 0xA0.
# Editar acá y regenerar: $SRW_PY tools/src/font_build.py
